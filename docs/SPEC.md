# 產品規格（已與使用者確認）

## 角色與場景
- **可能有多位老師**（例如 Joanna、Coco…），**每位老師的學生名單、上班時間、排課、通知完全獨立、互相看不到對方的資料**。老師之間要代課，是老師自己口頭溝通、在「請人代」欄位自己輸入名字（不是系統功能，系統不會去查詢或綁定其他老師的課表）。
- 一對一課，每堂 60 分鐘，原則上每週一堂但不綁死固定星期。
- 目標：**每月循環使用**；一個月請學生填寫一次。

## 時間規則
- 營業時間 10:00–22:00，最後一堂 21:00 開始。Joanna 可預約 13:00–22:00（可在老師端調整）。
- 每週固定封鎖一段時間（例：週三 16:00–17:00 公司開會，全工作室），**老師端可編輯星期與時間**，預設週三 16:00–17:00，很少變動。
- 起點對齊整點。

## 學生端（LIFF，手機優先）
- 標題用原訊息風格：「🌸 N 月皮拉提斯選課開始囉！」；顯示截止日、「27 日前安排完成、LINE 個別通知日期／時間／授課老師」。
- 選課提醒：60 分鐘、每週一堂、平日晚上熱門、選越多越容易但不保證第一志願、送出不等於預約完成、Joanna 額滿或休假會安排其他老師、時間都排不進去會另外聯絡。**不限制至少選幾個時段**。
- 選時段：以「一週的格狀圖」（橫＝一到日、直＝10:00–21:00）。點格子選取；**長按 0.3 秒後才能拖曳塗選**（直接滑動只捲動頁面，之前因鎖住捲動造成誤選已修正）；點星期標題整欄、點時間整列。
- 上方「範圍」切換：**整個月（每週相同，預設）**／只這一週（處理例外）。整個月模式下點到的格子套用到整個月相同星期與時段，並顯示提示。左右箭頭換週看例外。
- **有選＝可以、沒選＝不行**。沒有「指定時段」或「從幾點到幾點」模式（因為中間可能不行）。
- Joanna 不上班的時段學生也可選，以**斜紋＋虛線**顯示（比單純虛線明顯）並提醒「可能安排其他老師」。
- 下方「你目前的選擇」白話摘要（例：週一至週四 19:00–22:00；不行：10/16）。
- 「沿用上個月的選擇」：只帶入上個月「過半數週次都有選」的星期×時段，個別例外不帶入。
- 沒有個資同意勾選框，送出就算確認。沒有開放選課時顯示「目前沒有開放選課」與自己的課表。

## 老師端
- 底部分頁：上班時間／學生／排課／通知。最上方月份列（‹ 年月 狀態 ›）、截止日、「開始 N 月選課」。
- **上班時間**：用與學生相同的格狀選擇元件，預設整個月都上班；「連續休假」卡片在最上面（先設休假再細調）。下方自動產生「發給學生的本月上班時間」訊息（同時段的星期合併、列休假與臨時調整、含最後一堂時間、複製按鈕）。
- **學生**：列出本月已填／未填；「幫他填／修改」＝老師代填（同一個選擇元件，學生端看得到，標「老師代填」）；新增學生（不用 LINE 的學生）；**刪除學生**（直接刪除，不保留歷史紀錄；需二次確認；要重新收這位學生就重新登錄）。未填提醒：系統於截止前 2 天自動提醒，也有「現在就提醒」按鈕。
- **排課**：「自動排課」**可以分批按**——已經填寫的學生先排，還沒填的人填完後再按一次，不會動到已經排定的課，也不會把同一位學生排兩次（**沒有鎖定、也不會重新洗牌已排定的課**）。兩個學生時段相撞時，**選項最少的學生優先**（讓最多人排得進去）。只排老師自己（代課不算在自動排課裡）；排不進去的學生列入「待補其他老師」並寫原因與該週可上課時段；整週完全沒選時段則列為「順延」（不占用待補清單，也不安排代課）。之後全部手動：
  - 每堂「改時間」：列出學生同週選過且老師自己有空的時段，或自選日期＋時間；檢查衝堂與老師是否上班。
  - 每堂「請人代」：輸入代課老師名稱（自由輸入、記住歷史名稱、可用 ✕ 刪除），時間不變，課上標「代課：某某」；可改回老師自己。
  - 待補學生「安排老師與時間」：老師名稱＋學生選過的時段（或自選）。
  - 核准：若仍有待補，先提示、再按一次「確認核准」（不使用 confirm 彈窗，預覽環境會擋）。
- **通知**：核准後才產生；每位學生各自的課表訊息，含授課老師。已推播後，改時間／請人代／待補安排會**自動發訊息**給該學生並記錄；尚未推播時調整不發訊息，直接納入正式通知。

## 每月循環
- 週期＝一個月，狀態：collecting → draft（已自動排課）→ approved → notified。
- 「開始下月選課」僅在最新週期不是 collecting 時可按；開放後自動帶入上月的老師上班時段（過半數規則，休假不帶入），老師補休假。截止日預設今天＋7 天，可改。
- 跨月那一週（如 10/26–11/1）：下月排課時**扣掉上月已排在同一週的課**，同一週不重複排。
- 學生同時間只看到「最早一個 collecting 的月份」。

## 通知與 LINE 架構決定
- **所有老師共用同一個 LINE 官方帳號與同一個網站**；不需要每位老師各自申請官方帳號。資料庫裡每個學生、每一期排課都標記「屬於哪位老師」，老師登入後只看得到自己的部分（LINE 登入＋老師名單白名單，比對 LINE 使用者 ID）。
- 新增老師＝把對方的 LINE 帳號加進白名單（類似「新增學生」，但是「新增老師」），一次性設定，之後對方登入會自動被認出，不用自己選「我是誰」。
- LIFF 選時段頁面本身不需要官方帳號；學生開啟 LIFF 時自動用 LINE 身分登入，不用輸入帳密。
- **訊息則數限制與對策**：免費輕用量方案 200 則／月，而且是**所有老師共用同一個額度**，老師與學生數一多容易吃緊；群組推播是否依成員數乘算未確認（舊文章說會），需在後台實測。因此**每則要發的訊息都同時提供「分享／複製文字」按鈕**：
  - 老師端若在 LINE 內用 LIFF 開啟，按下去會跳出 LINE 原生的「選擇要傳給誰」畫面（`liff.shareTargetPicker`），直接挑群組或朋友送出，**這個方式完全不計入官方帳號的 200 則額度**（技術上等於老師自己分享，不是機器人推播）。
  - 不在 LINE 內開啟（例如用電腦瀏覽器）時，按鈕自動退回「複製文字」，老師自己貼到 LINE。
  - 官方帳號的自動推播（Push API）仍保留做為選項，但**不是唯一或預設的發送方式**。
- 付費方案價格 2026/11/1 調整，以後台為準。

## 已拿掉／不要做
- 「鎖定」課程、把**已經排定**的課重新洗牌（分批排課只處理「還沒處理過」的學生，不會動到已排定的課）。
- 隱藏學生（改為直接刪除，不保留歷史）。
- 「指定時段」的從幾點到幾點。
- 「每週至少選 3 個時段」限制。
- 系統層級的跨老師自動代課邏輯（排課只排該老師自己；代課由老師手動指定名稱，不會去查詢或綁定其他老師的真實課表）。
- 學生送出前的個資同意勾選框。
- 用 confirm/alert 彈窗當必要流程。
